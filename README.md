# Forest Cover Classification Project

This project focuses on classifying forest cover types using machine learning techniques. The goal is to predict forest cover types based on various terrain features and environmental factors.

## Project Overview

The project involves:

- Exploratory data analysis of forest cover types and terrain features
- Feature importance analysis
- Implementation and comparison of multiple machine learning models
- Detailed performance evaluation and misclassification analysis

## Files and Resources

- `final_ml_project_monish.ipynb`: Main Jupyter notebook containing the complete analysis and implementation
- `final_project_report_ml_spring_2025.pdf`: Detailed project report
- `final_project_images_ml/`: Directory containing all visualizations and plots

## Key Visualizations

The project includes several important visualizations:

### Data Exploration

- Forest cover type distribution
- Terrain feature distributions
- Elevation distribution by forest cover type
- Correlation heatmap of numerical features
- 3D visualization of key terrain features

### Model Analysis

- Model performance comparison across different algorithms
- Confusion matrices for:
  - Logistic Regression
  - Random Forest
  - LightGBM
- Feature importance analysis for Random Forest and LightGBM
- Per-class F1 score comparison
- Misclassification analysis by terrain features

## Methodology

The project follows a comprehensive machine learning pipeline:

1. Data preprocessing and exploration
2. Feature engineering and selection
3. Model implementation and training
4. Performance evaluation and comparison
5. Detailed analysis of results and misclassifications

## Results

The project demonstrates the effectiveness of different machine learning models in forest cover classification, with particular focus on:

- Model accuracy and performance metrics
- Feature importance in classification
- Analysis of misclassifications
- Impact of terrain features on classification accuracy

## Usage

To run the analysis:

⚠️ This is will take approx. **2 hour 30 mins** to run the whole notebook

1. Open the Jupyter notebook `final_ml_project_monish.ipynb`
2. Execute the cells in sequence to reproduce the analysis
3. The notebook contains detailed comments and explanations for each step
